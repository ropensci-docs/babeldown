# Check that two files have the same XML structure

Useful if
[`deepl_branch_update()`](https://docs.ropensci.org/babeldown/reference/deepl_update.md)
fails with an error about the XML structure. Checkout the default
branch, check the two files.

## Usage

``` r
check_xml_structure(path1, path2)
```

## Arguments

- path1:

  First path

- path2:

  Second path
